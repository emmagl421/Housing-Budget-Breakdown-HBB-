Housing-Budget-Breakdown
A AI powered website that helps you budget for a house/apartment Powered by Gemma 4 Model: gemma-4-26b-a4b-it

How to use
Step 1: Put in yearly salary/price range and a location for a house Then Gemma 4 will find housed that match your yearly income or price range and make a generic budget! Step 2: Put a listing you like Then Gemma 4 will create a more detailed budget for saving up to move in! Step 3: Filter by location or pet friendly Then Gemma 4 will find listings based on your preferences!

What Gemma does
Information flow
HTML -> script.js -> server.js -> SDK -> API -> Gemma 4

Notes
All listings and addresses are made up as I would need access to a API for real listings but the neighborhoods, ZIP codes, and coordinates are real

Because of this the way I find radius is not based on geocoding services but on the average position of every listing that matches the location by name
